# 产品与功能

## 1. 产品定位

气象资源空间智能平台以自部署 Open-Meteo 为气象底座，用 Cesium 展示空间和天气图层，把数据处理成可理解的预报、风光资源评估、风险提醒和报告。

核心闭环是：

```text
Open-Meteo 采集
    → 数据质量检查
    → 空间与时间序列分析
    → 风光资源评估
    → 风险提醒
    → 报告导出
    → 用户反馈与规则优化
```

## 2. 用户与目标

主要用户是新能源规划、气象分析、区域资源评估和运行值班人员。平台优先解决四个问题：

- 当前关注区域的天气和数据是否正常。
- 不同模型对未来天气的判断是否一致。
- 一个区域的太阳能、风能资源潜力如何。
- 风险是否需要提醒，能否形成可追溯的简报或报告。

## 3. 统一导航

| 导航 | 主要任务 |
| --- | --- |
| 总览 | 查看当前天气、24 小时趋势、数据新鲜度、资源潜力和风险摘要 |
| 空间 | 在 Cesium 中查看天气图层和关注点详情 |
| 预报 | 对比模型、查看变量趋势、集合离散度和历史回看 |
| 资源 | 评估自定义区域的太阳能与风能资源 |
| 风险 | 配置天气阈值、比较情景并生成提醒 |
| 数据 | 查看接口健康、变量覆盖、质量事件和报告生成 |

## 4. 功能模块

### 4.1 气象总览

面向快速判断，展示当前温度、风速、辐射、湿度、降水、云量、数据新鲜度和关注点风险。支持全球、重点区域和自定义关注点切换，点击卡片进入对应模块。

### 4.2 空间指挥台

基于 Cesium 提供 2D/3D 地图、时间轴、图层开关和空间查询。首批图层包括风场、辐射、云量、降水、洪水和空气质量。关注点详情统一展示坐标、当前天气、选中变量和相关风险。

### 4.3 预报与模型

支持 ECMWF、GFS、ICON 等模型对比，展示变量曲线、集合均值、离散度、置信区间和历史回看。用户可以选择关注点、变量、时间范围和模型，并将异常天气点加入风险规则。

### 4.4 风光资源评估

基于 GHI、DNI、GTI、风速风向、温度、海拔和地形，评估自定义区域或关注点的太阳能和风能资源。输出资源分布、月度变化、时间序列、区域对比和资源等级，不计算实际电站功率。

### 4.5 风险与情景

支持大风、暴雨、高温、低能见度、洪水、沙尘等阈值规则。用户可按区域和时间创建基准、保守、乐观等天气情景，查看影响差异并生成提醒。每条提醒必须关联数据时间、变量、阈值和关注区域。

### 4.6 数据与报告

提供 Forecast、Historical、Ensemble、Air Quality、Marine、Flood 等接口的健康状态、延迟、覆盖率、缺失率和质量事件。报告类型包括天气简报、资源评估报告和风险复盘，支持 Markdown/PDF 导出。

## 5. 功能边界

以下内容暂不进入 V0.2：

- 电站、风机、逆变器、组件组和电表资产管理。
- SCADA、实际发电量、功率偏差和弃电计算。
- 调度执行、交易申报、电价、负荷和储能控制。
- 以设备可利用率为输入的功率预测闭环。

如果未来接入这些能力，应新增版本和数据模型，不得直接修改 V0.2 的语义。

## 6. 核心验收场景

1. 用户新建关注点并输入坐标后，系统能显示时区、海拔、当前天气和预报。
2. 用户在 Cesium 中切换图层、拖动时间轴并点选关注点，右侧详情随上下文更新。
3. 用户能对同一变量查看至少两个模型，并看到模型差异和集合范围。
4. 用户能对一个区域生成太阳能、风能资源评估，并导出报告。
5. 用户配置风险阈值后，满足条件时生成提醒，提醒包含触发证据和数据时间。
6. 数据断流时，页面显示明确的过期或降级状态；恢复后自动补采并更新质量指标。

## 7. 待确认产品决策

- 第一批关注区域按全球、全国还是指定省市启动。
- Cesium 底图和地形是否全部内网部署，或允许 Cesium ion/第三方瓦片。
- V0.2 是否需要单组织单租户，还是预留多组织字段。
- 报告是否需要企业微信通知或共享链接。
